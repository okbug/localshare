# 可选的跨屏滚轮与修饰键映射

每个已配对设备提供两个本地开关：`invertScroll`（反转横向和纵向滚轮）和 `swapAltWin`（交换左右 Alt / Option 与左右 Win / Command）。默认均为 false，旧配对记录缺失字段也按 false 读取。保存在本机 trust.json；不修改系统键位，不同步到对端。

开关放在设备协同的对应设备卡片下，说明「仅影响本机控制该设备时的输入，下一次跨屏生效」。Windows 控制 Mac 时，开启交换后左/右 Alt → 左/右 Command，左/右 Win → 左/右 Option。也允许反方向按同一规则选择交换；Control、Shift、普通键、点击、移动保持现有行为。不开启的设备不受影响。

在发送端 Control 会话创建时复制这两个选项，发送前映射事件；一次会话使用同一份配置，保证键按下/抬起一致。原始事件验证仍先执行；只映射 Windows 虚拟键 164↔91、165↔92。无需更改网络协议或原生辅助程序，旧对端仍可接收标准输入事件。滚轮两个非零分量取反，零保留 0。

setPeer 对整个补丁先校验再修改，防止无效混合补丁部分改变状态。新布尔值通过 IPC 白名单与核心双重校验。

验证：真实双服务的有序事件链路覆盖关闭、开启、独立开关、左右修饰键、按键松开、不同设备/反方向隔离及会话中修改；存储测试覆盖旧记录迁移、重载保留、无效类型拒绝。Electron 冒烟通过真实 UI 点击及 IPC 回读验证开关默认、开启、关闭；原生注入仍由已有辅助程序处理。物理双机手感不能用回环测试代替。
