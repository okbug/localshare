# 键鼠共享开启引导与错误提示修复

2026-11-04：用户遇到 `{"error":"键鼠共享未开启"}`，没有得到明确的双端配置说明。

现有条件：双方必须配对、分别打开键鼠总开关、分别为对方打开设备卡片的共享键鼠开关；Mac 需系统辅助功能权限。总开关在每次应用启动后关闭。原错误由接收端产生，但网络层把 JSON 原文当作错误消息，且界面把远端错误也放进“检查权限”区域。

本次方案：
1. 为“本机配置完成，但对方总开关关闭”和“对方未授权对应设备”添加真实双实例 HTTPS 回归测试。
2. 接收端错误说明包含设备名称和具体的开关路径，网络层提取 JSON 中的人类可读错误，兼容纯文本错误响应。
3. 设备协同页常驻四步说明、Mac 权限位置、左右布局示例和重启后重新开启的说明；把远端错误提示与权限检查分开。
4. 构建与测试后推送 main。此轮不自动开启任何设备共享权限；已安装的 0.1.0 / 0.1.1 按聊天和 README 中的步骤即可配置。

验证：修复前，双实例测试复现了原始 JSON 报错且无法指出接收端设备。修复后，同一测试验证接收方总开关和设备卡片开关的不同提示，全部开启后控制会话成功建立；14 项功能测试通过，发行包签名用例在未指定产物路径的本轮测试中跳过。严格类型检查、构建及双实例 Electron 界面流程通过，设备协同页可见开启引导。此次只更新 main，未替换已发布安装包。
